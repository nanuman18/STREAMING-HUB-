Plataformas

Cada plataforma es un addon con sus catálogos de películas y series. Instala las que quieras; Stremio las muestra en el orden en que las instales.

    Orden de los títulos

    Para cambiar el orden de una plataforma ya instalada, vuelve a instalarla con el nuevo orden: sustituye a la anterior.

    Cómo instalar

    1. Instalar abre la app de Stremio (escritorio, Android, Android TV).
    2. Web abre Stremio Web, útil para sincronizarlo con tu cuenta y verlo después en la tele.
    3. Copiar copia la URL para pegarla en Stremio → Addons.
